# ATools: CopyFull

Исправление для CopyFullHist в ReallyTools (AdminTools Spidi 1.2.1), Fabric 1.21.4. Положите JAR дополнения рядом с ATools и включите CopyFullHist. Кнопка в чате остаётся прежней.

- `.copyfull PlayerName 1000 true` — история персонала через `/shist`.
- `.copyfull PlayerName 1000 false` — история игрока через `/hist`.

В буфер попадают даты, наказания, причины, строки окончания, разбанов и размутов. Посторонний чат не завершает сбор. Если ответ оборвался или началась другая история, прежнее содержимое буфера сохраняется.

Если записей меньше лимита, дополнение один раз запрашивает историю повторно и сверяет состав записей. Пустая история не заменяет содержимое буфера.
